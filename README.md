# Simple Interest Calculator

A simple Bash script designed to calculate simple interest based on user inputs.

## Project Description
This project provides a straightforward tool to compute the simple interest for a given principal amount, annual rate of interest, and time period in years. It is built as part of the IBM Git & GitHub course project.

## Formula
The simple interest is calculated using the standard formula:

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal amount
- **R** = Annual interest rate (in percentage)
- **T** = Time period (in years)
